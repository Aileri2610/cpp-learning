1. Git là gì?
    Git là một hệ thống quản lý phiên bản lưu trữ từng snapshot của dữ án.
2. Repository là gì?
    Là tập hợp các file và thư mục được tạo bởi Git để quản lý phiên bản của dự án. 
3. Working Directory.
    Là nơi làm việc của dự án, nơi có thể chỉnh sửa, thay đổi các file và thư mục.
4. Staging Area.
    Là nơi tạm lưu trữ các thay đổi, chọn lọc các file và thư mục để commit vào repository.
5. Local Repository.
    Là bản sao đầy đủ của repository được lưu trữ trên máy tính cục bộ.
6. HEAD.
    Là một con trỏ tham chiếu đến commit hiện tại trong repository.
